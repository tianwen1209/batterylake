Output Schema

metadata.json
Cell-level metadata: chemistry, form factor, nominal capacity, source lab, test conditions, publication DOI.
timeseries.parquet
Raw measurement time-series: voltage_V, current_A, temperature_C, capacity_Ah, timestamp - per cycle per cell.
cycle_summary.csv
Cycle-level aggregates: discharge capacity, charge capacity, coulombic efficiency, IR, cycle number - one row per cycle.
dataset_note.md
Human-readable documentation: data provenance, known issues, preprocessing decisions, and usage recommendations.
