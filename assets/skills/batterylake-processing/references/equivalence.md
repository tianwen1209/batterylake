# 原始路径与标准路径的 benchmark 等价性契约

## 比较对象

对每个数据集、每个 profile 固定一份配置，并保存 SHA-256：

- 数据版本、物理电芯/实验集合、测试窗口、源记录键、有效掩码、排除理由。
- 输入通道及顺序、单位、时间/电压网格、插值/截断/padding、窗口长度、特征算法及 dtype。
- 标签来源、容量基准、EOL、RUL 单位、删失处理、标签可用时间。
- split 的电芯/模块/批次分组与固定顺序。窗口任务防止重叠窗口跨 split；同物理电芯的文件、派生副本和寿命阶段不可跨训练/测试。
- scaler、缺失值估计器和任何训练得到的预处理仅拟合训练集；不使用测试统计、未来循环、RUL/EOL 或完整寿命长度构造输入。作者 split 另存为 author profile；若存在泄漏，应明确标注，另建严格 profile，不能在复现比较时悄悄换 split。
- 相同初始化/checkpoint、随机种子列表、batch 及顺序、optimizer、损失、epoch、早停、代码/依赖/设备精度和确定性选项。

保真层不重采样；CNN 要定长张量时在双方共享的 benchmark 特征阶段进行。为了跨数据集统一训练而改变标签或输入协议，应命名为新 profile；它与作者任务的分数无需相同，不能包装成转换无误差的证据。

## 分级检查

1. **全量结构和数值**：遍历所有输入和输出，核对来源映射、记录数、ID、次序、重复记录、缺失模式和所有源字段覆盖。标准列按逆单位变换对照源值；二进制数组核对 dtype/shape/值。非一一映射有明确的矩阵/拆分规则。每个字段输出 count、max_abs_error、max_rel_error、p50/p95/p99 及差异源定位。
2. **独立原始 loader**：按作者说明或独立实现直接读原文件，不调用 adapter 的单位/边界/标签映射函数。另一路只读标准产物。两条路径可以共享比较之后的特征/模型代码，但不能共享待验证的转换逻辑。若原始路径缺失，报告 not_run。
3. **输入和目标一致**：同 source/sample key 排列，比较 X、y、mask、time grid、split、样本顺序及样本数量。ID、维度和掩码必须完全相同。固定若干边界病例仅用于快速调试；发布前全量比较全部目标样本，不把抽样通过写成全量通过。
4. **固定模型推理**：同一个冻结 CNN/checkpoint，分别输入两路张量，比较每个预测和损失；这一步隔离训练随机性。记录模型结构及 checkpoint hash。合成模型可以验证管线，但必须标明不是作者模型复现。
5. **配对训练**：对同一随机种子、同一初始化和 batch 顺序运行两路训练。记录每个种子的 MAE/RMSE、最大预测差、学习曲线和配对差异。可确定性复现时优先要求相同输入张量哈希和结果；存在不可消除的非确定性时，先测量 raw→raw 重复波动，再按预注册的种子数/等价界限评估 raw→standard。仅均值接近或统计“不显著”不足以证明等价。

## 容差与报告

不使用一个覆盖全部字段的宽松 epsilon。ID、记录次序、缺失掩码与整数要求 exact。仅重命名/无算术的 float64 数值要求相等；单位换算按预先声明的表达式评估舍入误差。可先以 `atol=1e-12`（标准单位）、`rtol=1e-12` 作为 float64 诊断起点，但须按数值范围、原始精度和变换链审查；不是所有数据自动使用此门槛。时间采用源时间分辨率对应的整数基准，不能随意放宽至 1 秒。

积分容量/派生特征的误差与直接存储误差分别报告；作者方法未知时不得通过调宽容差强行通过。定义阈值的配置先落盘再比较，失败时修复方法或记录真实差异，禁止结果出来后改阈值至通过。

SOH MAE 必须说明比例还是百分点；RUL MAE 必须说明 cycles/EFC/小时。模型层容差使用明确的业务等价界限和 raw→raw 波动证据，不强行规定任意百分比。

每份报告记录实际 command、时间、输入/配置/模型/代码指纹、软件和硬件、比较数量、数值容差、结果、最差样本、未运行项及原因。某模型通过只证明这个数据版本和 profile；不代表任意 CNN 或任意原始数据处理方法都会一样。

PyTorch 明确说明跨版本、平台的结果不保证完全可复现；固定随机源与确定性算法是对照条件的一部分，参见[官方说明](https://docs.pytorch.org/docs/stable/notes/randomness.html)。
